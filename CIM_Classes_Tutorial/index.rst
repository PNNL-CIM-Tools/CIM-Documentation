.. CIMantic Graphs

================================================
CIM Classes Tutorial
================================================

This library provides an overview of usage of the UCAiug Common Information Model (CIM) and mappings to the IEC 61970, 61968, and 62325 standards for modeling power systems equipment, assets, and markets.

All examples are based on usage of the CIMantic Graphs python library developed by Pacific Northwest National Lab (PNNL).

To install CIMantic Graphs clone the github repository or use pip install: `pip install cim-graph`
